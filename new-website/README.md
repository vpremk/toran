# Toran

A premium Indian ethnic fashion storefront MVP with a matching admin/CMS prototype built in Next.js.

## Features

- Luxury storefront for Indian ethnic fashion
- Three fixed categories:
  - Sarees
  - Indo-Western
  - Kurta Pyjama
- Product listing, collection pages, product detail pages, and cart flow
- Simple admin interface at `/admin` for:
  - Dashboard
  - Products
  - Categories
  - Homepage Content
  - Store Settings
- Shared mock data layer with typed models for products, categories, homepage content, and store settings
- Responsive design using Next.js + TypeScript + Tailwind CSS

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Getting Started

1. Install dependencies:
   npm install
2. Start the development server:
   npm run dev
3. Open http://localhost:3000

## Admin

Visit:

- http://localhost:3000/admin

## Notes

This project uses browser-local storage for the prototype CMS data layer. It is intended for demo use and is not a production-secure or multi-device shared backend.

## Available Scripts

- `npm run dev` - Start the app in development mode
- `npm run build` - Build the app for production
- `npm run start` - Start the production build
- `npm run lint` - Run ESLint
